# control run refuses any other test that passes against nothing, because the
# judge is handed a count and a test that cannot fail inflates it.
#
# One name per line. Adding one is a decision: say in a comment why the thing it
# looks for is absent from an empty tree for the same reason it must be absent
# from a finished one.
