## Defect: private CSV written to disk before the audit record

`src/seating_planner/export/csv_export.py`, `GuestToTableExport.write`: `path.write_text(self.csv_text, ...)` runs before the audit log is opened. The module docstring and spec (FR-085/AC-004) say a private export never reaches disk without its audit record, but the code only refuses when `audit_log is None`. If the audit path cannot be opened, the CSV is already on disk and no audit line exists. No test covers it.

Demonstration (gate image, `git archive` export, `--network none`): export `locked_to_table`, call `write(out, audit_log=<dir>/nodir/audit.jsonl)`:

    raised FileNotFoundError
    csv on disk: True
    guest_id,guest_name,rsvp_status,table_id,table_name,locked_to_table
    g1,"=HYPERLINK(""http://x"",""a"")",Confirmed,t1,T1,t1

Fix: append the audit line first, or write the CSV to a temp file and rename after the audit succeeds; add a test with an unwritable audit path asserting no CSV exists.
