- **The change.** It adds a new file, `src/tictactoe/session.py` (57 lines). `GameSession` holds a `Board`, a `result` and a `message`. `move(cell)` returns at once if the game is over. Otherwise it calls `board.apply_move(cell)`, which raises `ValueError` and changes nothing on an illegal cell, then settles. If the game is still live, O replies with `apply_move(choose_move(board, O))` and the session settles again. `new_game()` swaps in a fresh `Board` and clears the result and message. Every rule is delegated: there is no second line table, no direct write to `cells`, and no `tkinter` or `random`. It also adds `tests/test_session.py` with the seven tests the acceptance criteria name. The diff is 156 lines over 2 files, all inside `allowed_write_paths`, and no forbidden path is touched.
