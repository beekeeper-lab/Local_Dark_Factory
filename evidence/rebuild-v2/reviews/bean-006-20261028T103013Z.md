## 1. The fix itself

`src/seating_planner/solver/hard.py:152-158`:

```python
status = solver.solve(model)
if status == cp_model.INFEASIBLE:
    return SolveResult(status="infeasible", assignments={})
if status not in (cp_model.OPTIMAL, cp_model.FEASIBLE):
    raise SolverTimeout(
        f"no table-level assignment settled within {cfg.time_limit_s}s: "
        f"solver reported {status!r}"
    )
```

A proven negative (`INFEASIBLE`) still returns the `"infeasible"` result. Anything else unsettled
(in practice, `UNKNOWN`) now raises `SolverTimeout(RuntimeError)` instead of being folded into
`"infeasible"`. `SolverTimeout` is defined at `hard.py:37-43` and exported from
`src/seating_planner/solver/__init__.py`.

## 5. Docstrings

the corrected contract: `"infeasible"` means CP-SAT *proved* no assignment exists; an unsettled

never reported as `"infeasible"`. `SolverTimeout`'s own docstring (`hard.py:38-43`) restates the
same distinction. All three agree with each other and with the code — no stale language left over
from the pre-fix "a solver status that is not a proven answer is reported infeasible" framing that
round 1 quoted as the root of the bug.
